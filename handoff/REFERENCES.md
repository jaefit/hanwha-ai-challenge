# 디자인 레퍼런스 — "AI 틱함" 빼기

작성 2026-08-29. Claude Design에 붙여 넣을 목록. 전부 **실제 운영 중인 상태판·대기시간·인파 서비스**다. 예쁜 사이트가 아니라 *현장에서 쓰이는 정보 화면*을 베낀다.

## 핵심 방향 한 줄
우리 화면은 랜딩페이지가 아니라 **역 전광판 / 놀이공원 대기시간판 / 지하철 운행상태판**이다. 히어로 이미지·그라데이션·아이콘 카드 3열·"AI 기반" 문구·보라색 전부 금지.

## 해도 되는 것 / 하면 안 되는 것

| 하기 | 하지 않기 |
|---|---|
| 리스트·표가 화면의 80% | 히어로 배너, 풀스크린 배경 사진 |
| 한 줄에 상태 한 단어 + 숫자 + 색띠 | 아이콘 카드 3열, 원형 게이지, 도넛 차트 |
| 갱신 시각·출처를 본문 크기로 | "AI가 분석한", "스마트", "혁신" 카피 |
| 등급색 = 서울시 4단계(초록·노랑·주황·빨강) | 보라·네온 그라데이션, 글래스모피즘, 블러 |
| 한화 오렌지는 로고·탭 선택·CTA 딱 3곳 | 오렌지 배경 전면, 오렌지 = 경고색 혼용 |
| 야간 화면: 진한 남색/검정 바탕에 밝은 글자 **또는** 흰 바탕 고대비 중 하나로 통일 | 반투명 카드가 겹치는 다크 UI |
| 숫자는 탭ular(고정폭) 정렬 | 장식용 큰 숫자 + 작은 라벨 조합만 반복 |
| 무정차·통제 행은 회색+빗금+사유 | 오류·빈 화면을 일러스트로 덮기 |

## 프롬프트에 그대로 붙일 문장
"이 화면은 TfL 운행상태판(https://tfl.gov.uk/tube-dlr-overground/status/)과 놀이공원 대기시간표(https://queue-times.com/en-US/parks/274/queue_times)를 합친 **정보판**이다. 랜딩페이지가 아니다. 리스트가 UI의 80%, 등급색은 서울시 실시간 도시데이터 4단계(여유·보통·약간붐빔·붐빔)를 그대로, 한화 오렌지는 로고·선택 탭·CTA 세 곳만. 히어로 이미지·그라데이션·아이콘 카드·보라색·'AI' 문구 금지. 서체 Pretendard, 숫자는 고정폭. 데스크톱 1440, 2열(왼쪽 출구 보드, 오른쪽 지도)."
