## 3. 시스템 (2026-08-29 현재 상태)

```
[사전, 라이브 없이 완결]
  data/raw (KT OD 목적·수단, OA-12921 승하차)  ──src/baseline.py──▶ data/derived/baseline.json
                                              ──src/backtrack.py─▶ data/derived/feeder_origin.json
                                                                   data/derived/exit_forecast_2026.json ──복사──▶ docs/data/
[당일, 선택 레이어]
  서울 실시간 도시데이터 ──src/collector_api.py(5분)──▶ data/live/api_YYYYMMDD.jsonl ─┐
  TOPIS CCTV 23대 ────src/collector_cctv.py(60초)──▶ data/live/cctv_YYYYMMDD.jsonl ─┼─▶ src/nowcast.py ─▶ forecast_latest.json
  data/live/show_end.txt (쇼 종료 실제 시각) ─────────────────────────────────────────┘        │
                                                                               src/publish.py ─▶ docs/data/latest.json (commit+push)
[화면]
  docs/index.html — latest.json 있고 12h 이내면 라이브, 아니면 exit_forecast_2026.json(사전 예측, 밴드 표시). 5분 fetch, localStorage 폴백.
```

구성요소별 계약:

| 구성요소 | 입력 | 출력 | 상태 |
|---|---|---|---|

| `nowcast.py` | 사전표 + 오늘 도시데이터·CCTV + show_end | α(격자 사후분포 p50, 8/30 T1c), 출구별 load/lo/hi(α p10/p90)/wait, 지연표, 통제, `assimilation` | 완료. CCTV 입력은 캘리브레이션된 카메라만 |
