한화 신입사원 AI 실습 과제. 5개 과제 중 **03 「고객 페인포인트 해결」** 을 선택해 수행한 작업 기록이다.

## 현재 상태 (2026-08-27)

주제를 **F3 — ETF 이름만으로는 무엇이 들었는지 모른다** 로 확정했고, 가상 데이터 없이
공시 실데이터로 산출물 시제품(ETF 해부 카드 3장)까지 만든 단계다.

핵심 발견: `PLUS K방산` ETF 는 이름과 달리 **한화 3사가 51.04%** 를 차지한다.
페인포인트의 실증 사례이면서 동시에 자사 상품이라 발표 소재로 강하다.
